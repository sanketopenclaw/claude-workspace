# Crypto Picks Copy + Visibility Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make symbol, stop, entry, and 2R target individually click-to-copy in both pick card components, and increase price/symbol font sizes for legibility.

**Architecture:** Two focused edits to `crypto.jsx` — one per pick component (`PickCard`, `ScanFeedItem`). Each gets a `copied` state + `copyField` helper that writes to clipboard and flashes the label to `✓` for 900ms. Font sizes bumped in the same pass. Bundle rebuild required after.

**Tech Stack:** React (useState), `navigator.clipboard.writeText`, `node dashboard/build.js`
